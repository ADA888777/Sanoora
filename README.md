# سانورا — أكاديمية اللغات الاحترافية

موقع تعريفي (صفحة واحدة) لأكاديمية «سانورا» لتعليم اللغات، مبني بـ HTML و CSS و JavaScript خام بدون أي إطار عمل أو اعتماديات.
التسجيل في الدورات يتم بالتحويل المباشر إلى تيليجرام، ولا توجد بوابة دفع داخل الموقع.

## المزايا

- واجهة عربية بالكامل باتجاه RTL.
- عشر لغات معروضة: الإنجليزية، الإسبانية، الفرنسية، الألمانية، الإيطالية، الصينية، اليابانية، البرتغالية، الكورية، الروسية.
- تحويل تلقائي لسعر الدورة إلى عملة الزائر (SAR, EGP, AED, JOD, KWD, USD, EUR, QAR, OMR, BHD) اعتماداً على بلده، مع رجوع آمن إلى الريال السعودي عند تعذر تحديد الموقع.
- نوافذ منبثقة لسياسة الخصوصية والشروط والدعم والتواصل، مع دعم لوحة المفاتيح وسمات ARIA.
- أسئلة شائعة قابلة للفتح والإغلاق.

## هيكل المشروع

| الملف | الوصف |
| --- | --- |
| `index.html` | بنية الصفحة كاملة مع التنسيق الداخلي. |
| `style.css` | تنسيق أساسي مساعد. |
| `script.js` | تحديد الموقع، تحويل العملة، النوافذ المنبثقة، الأسئلة الشائعة، والتأثيرات. |
| `server.js` | خادم ملفات ثابتة بسيط بـ Node.js للتشغيل المحلي. |
| `attached_assets/` | الشعار وملفات مرجعية قديمة من مرحلة التطوير. |
| `.replit` | إعدادات بيئة Replit. |

## التشغيل محلياً

المشروع لا يحتاج أي تثبيت. يكفي أحد الخيارين:

```bash
# 1) عبر خادم Node.js المرفق
node server.js
# ثم افتح http://localhost:5000

# 2) أو بأي خادم ملفات ثابت
python3 -m http.server 5000
```

يمكن أيضاً فتح `index.html` مباشرة في المتصفح، لكن يُفضّل استخدام خادم محلي حتى تعمل طلبات تحديد الموقع بشكل صحيح.

## النشر

الموقع منشور عبر GitHub Pages من الفرع `main`، ويمكن نشره كموقع ثابت على أي مزوّد آخر بنسخ ملفات المستودع كما هي.
